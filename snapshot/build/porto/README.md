# פורטו: סדר הבנייה (נתונים 2026.11.02a)

נבנתה לפי ה-Playbook (v1.20.2). 292 כרטיסים בקובץ העיר (189 אתרים + 20 אטרקציות + 83 יצירות "בסיסי" מ-OSM, ועוד 3 אתרים קיימים שמסומנים כיצירות), 234 יצירות נוספות בקובץ "כל היצירות", 24 אירועים, מדריך עיר ומטבע. נקודת הבסיס: פראסה דה ליברדאדה (אליאדוס).

## קבצים
- `plan.py`: תוכנית האתרים (קטגוריה, שם, קואורדינטות ראשוניות, רמה, דירוג, הערות לכותב). `parts.py`: חלוקה לקובצי batch.
- `batch_*.py`: כרטיסי האתרים לפי רובע (14 קבצים). `batch_fun.py`: אטרקציות (סעיף 2א), לפי `fun_input.json` ו-`FUN_GUIDE.md`. `guide.py`: מדריך העיר והמטבע. `events.py`: אירועים.
- `fixes.py`: אתרים שהוסרו, וקואורדינטות ורובע שתוקנו (נכתב בידי `tools/mkfix.py` אחרי אימות מול OpenStreetMap).
- `merge.py`: מיזוג לקובץ העיר. `check_batch.py`, `check_fun.py`, `check_guide.py`, `check_events.py`: בדיקות.
- `WRITING_GUIDE.md`, `REVIEW_GUIDE.md`, `FUN_GUIDE.md`: הנחיות הכתיבה והביקורת. `review/`: דוחות הסוקרים העצמאיים (סעיף 9.10).
- `../art/porto/`: היצירות. `input/c01..c12.json` נתוני המקור (OSM + ויקידאטה) אחרי סינון, `c01..c12.py` הכרטיסים (349 נכתבו, 30 הוסרו ב-`marks.py` SKIP אחרי הביקורת: בשטח פרטי או בתשלום, אינם יצירה, או בלי מידע), `geo.py` שיוך רובע ומרכז לפי קואורדינטות (קו הנהר דורו מפריד בין פורטו לגאיה), `marks.py` (MARK: 3 כרטיסים קיימים שמסומנים כיצירות; SKIP), `ART_GUIDE.md`, `check_art.py`.
- `tools/`: איסוף הנתונים. מעכשיו רץ ב-GitHub Actions במאגר `daddycoolix/triparty` (`collect/collect.py`, `jobs/porto.json`, תוצאה ב-`data/porto/`), והסביבה בענן מושכת משם. `gen_por.py` ו-`triparty-porto-data.cmd` הם הגרסה הישנה שרצה במחשב של בעל היישום. `nom.py` ו-`mkfix.py` מאמתים קואורדינטות ויוצרים את `fixes.py`; `artprep.py` ו-`artsplit.py` מסננים ומחלקים את היצירות; `poi.py` חיפוש בנתוני OSM.

## סדר ההרצה
```
cd build/porto && python3 merge.py 2026.11.02a            # כותב triparty-Porto.json (בלי יצירות)
cd ../art && python3 merge_art_city.py Porto 2026.11.02a   # מוסיף "בסיסי", כותב triparty-Porto-art.json, מעדכן cities.json
```
אחר כך: עדכון `on`, `all`, `base`, `allN` של Porto ב-`triparty-art-settings.json`, ו-`version.txt`.
קובצי ה-HTML לא שונו: פורטו נטענת מ-`cities.json`, והגדרות היצירות שלה מ-`triparty-art-settings.json` שבאתר.

## מה לא אומת
מחירים, שעות וסטטוס פתיחה נכתבו מידע כללי ומסויגים בטקסט. הקואורדינטות אומתו מול OpenStreetMap (127 תוקנו). כרטיס בית חב"ד כתוב במפורש כלא מאומת; המסעדה הכשרה לפי רישום OSM בלבד. פירוט ב-`review/`.
