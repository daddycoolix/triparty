# ליסבון: סדר הבנייה (נתונים 2026.11.05a)

העיר נבנתה לפי ה-Playbook (v1.20.2).

**קובץ העיר: 354 כרטיסים**
- 250 אתרים: 252 בתוכנית, ו-2 כפילויות הוסרו אחרי הביקורת.
- 19 אטרקציות: 22 נכתבו, ו-3 הוסרו אחרי האימות באינטרנט.
- 85 יצירות "בסיסי" מ-OSM.
- 9 אתרים קיימים שמסומנים כיצירות.

**עוד באותה גרסה**
- 239 יצירות נוספות בקובץ "כל היצירות".
- 28 אירועים.
- מדריך עיר ומטבע.

נקודת הבסיס היא הרוסיו (פראסה דום פדרו הרביעי).

## קבצים
**תוכנית ותוכן**
- `plan.py`: תוכנית האתרים. לכל אתר: קטגוריה, שם, קואורדינטות ראשוניות, רמה, דירוג והערות לכותב.
- `parts.py`: חלוקת התוכנית לקובצי batch, עד 20 אתרים בכל קובץ.
- `batch_*.py`: כרטיסי האתרים לפי רובע, 17 קבצים.
- `batch_fun.py`: האטרקציות (סעיף 2א), לפי `fun_input.json` ו-`FUN_GUIDE.md`.
- `guide.py`: מדריך העיר והמטבע.
- `events.py`: האירועים.
- `fixes.py`: אתרים שהוסרו (DROP) וקואורדינטות ורובע שתוקנו (FIX).
  - רוב FIX נכתב בידי `tools/mkfix.py` אחרי אימות מול OpenStreetMap, ו-151 קואורדינטות תוקנו כך.
  - בקובץ גם תוספות ידניות: Tapada de Mafra (רובע "מחוץ לעיר"), Doca de Belém, וכל ה-DROP.
  - **הרצה חוזרת של mkfix דורסת את הקובץ**, ולכן אחריה צריך להחזיר את התוספות הידניות.

**מיזוג ובדיקות**
- `merge.py`: מיזוג לקובץ העיר.
- בדיקות: `check_batch.py`, `check_fun.py`, `check_guide.py`, `check_events.py`.

**הנחיות וביקורת**
- `WRITING_GUIDE.md`, `REVIEW_GUIDE.md`, `FUN_GUIDE.md`: הנחיות הכתיבה והביקורת.
- `review/`: דוחות הסוקרים העצמאיים (סעיף 9.10) ודוחות האימות באינטרנט (`web_*`).

**יצירות (`../art/lisboa/`)**
- `input/c01..c14.json`: נתוני המקור (OSM וויקידאטה) אחרי סינון.
- `c01..c14.py`: כרטיסי היצירות. נכתבו 380, ו-56 הוסרו אחרי הביקורת דרך SKIP ב-`marks.py`. סיבות ההסרה: שטח בתשלום או סגור (הקאשטלו, אשטופה פריה, הגנים הבוטניים, מונטיירו-מור), מחוץ לעיר (אמדורה, אודיבלאש, לורש), שאינו יצירה, או שאין עליו מידע.
- `geo.py`: שיוך רובע ומרכז לפי קואורדינטות. קו הטז'ו מוגדר ב-`river()`.
- `marks.py`:
  - MARK: 9 כרטיסים קיימים שמסומנים כיצירות.
  - SKIP: היצירות שהוסרו.
- `ART_GUIDE.md`, `check_art.py`: הנחיות הכתיבה ובדיקת הכרטיסים.

**איסוף נתונים (`tools/`)**
- האיסוף רץ ב-GitHub Actions במאגר `daddycoolix/triparty`:
  - הקוד: `collect/collect.py`.
  - ההגדרה: `jobs/lisboa.json`.
  - התוצאה נכתבת ל-`data/lisboa/`.
- `nom.py` ו-`mkfix.py` מאמתים את הקואורדינטות.
- `artprep.py` ו-`artsplit.py` מסננים את היצירות ומחלקים אותן לקבוצות.

## סדר ההרצה
```
cd build/lisboa && python3 merge.py 2026.11.05a              # כותב triparty-Lisbon.json (בלי יצירות)
cd ../art && python3 merge_art_city.py Lisbon 2026.11.05a     # מוסיף "בסיסי", כותב triparty-Lisbon-art.json, מעדכן cities.json
```
אחרי שתי ההרצות צריך לעדכן ידנית שני קבצים:
- ב-`triparty-art-settings.json`, בערך של Lisbon: `on=1`, `all=1`, `base=94`, `allN=239`.
- `version.txt`.

קובצי ה-HTML לא שונו:
- ליסבון נטענת מ-`cities.json`.
- הגדרות היצירות שלה נטענות מ-`triparty-art-settings.json`.
