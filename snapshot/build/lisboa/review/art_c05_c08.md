# סקירת יצירות ליסבון: c05, c06 (אבנידה דה ליברדדה ואוונידאש נובאש), c07, c08 (בלם ואז'ודה)

## שינויים

### c05 (אבנידה דה ליברדדה ואוונידאש נובאש, חלק ב)
1. [פסל החזה של סזאריו ורדה] דיוק: "רוב שיריו התפרסמו רק אחרי מותו" -> "שיריו קובצו לספר רק אחרי מותו" (הספר יצא ב-1887). בטיפ: מזרקת נפטון "כמה עשרות מטרים" -> "כ-100 מטרים" (לפי הקואורדינטות).
2. [קונטרפונטו] ניסוח: "השם 'קונטרפונקט' לקוח" -> "השם, 'קונטרפונקט' בספרדית, לקוח". שם היצירה הוא Contrapunto.
3. [פסל החזה של ד״ר פרנסישקו ג'נטיל מרטינש] מונח פנימי וסיוג: "שם המונצח מרמז על קשר משפחתי, אך הקלט אינו מפרט" -> "מרמז, ככל הנראה... אך ב-OSM אין פרטים".
4. [שני פסלי הילדים בפארק אדוארדו השביעי] פרט לא בקלט: "חלק מעשרות פסלים שהעירייה הציבה בפארק" -> "לפי תיאור העירייה הם פסלים דקורטיביים... אחד מפסלים רבים שהוצבו בפארק".
5. [האישה היושבת / האישה עם האייל] אחידות תעתיק: "סטלה דה אלבוקרקי" -> "סטלה דה אלבוקרקה" (ב-h, בטקסט וב-`by`), כמו אפונסו דה אלבוקרקה ב-c07. הכללה: "סגנון שאפיין את הפיסול" -> "סגנון שהיה נפוץ".
6. [פסל האישה השרועה] פרט לא בקלט: "מונחת על הדשא" -> "משתלבת בנוף של הפארק".
7. [פסל הלוחם של קוטיליירו] שגיאת מרחק: "בפראסה ז'וזה פונטנה הקרובה" -> "כקילומטר וחצי דרומה" (1.4 ק"מ לפי הקואורדינטות). אחידות תעתיק: "קוטילירו" -> "קוטיליירו" (גם ב-`by` ובאנדרטת ז'וזה פונטנה), כמו ב-c04 וב-c10.
8. [אנדרטת 25 באפריל בקמפו סנטנה] ניטרליות: "הפילה תנועת קצינים צעירים את משטר האסטדו נובו" -> "הביאה תנועת הכוחות המזוינים, בהובלת קצינים צעירים, לסיום משטר האסטדו נובו". ניסוח ב-d ("מתואר בתיאור העירייה" -> "שהעירייה מתארת"). מיקום: "רוי פריירה יצר בגן הזה גם" -> "באזור קמפו סנטנה"; האנדרטה לתרזה דה סלדניה נמצאת כ-300 מ' צפונה, מחוץ לגן. גם בטיפ.
9. [אנדרטת האם תרזה דה סלדניה] מיקום בטיפ: "גן קמפו סנטנה הסמוך, שבו עוד יצירות" -> "כ-300 מטרים דרומה, שבסביבתו עוד יצירות".
10. [אנדרטת ז'וזה פונטנה] מיקום בטיפ: "באותה כיכר" -> "בסביבת הכיכר, כ-100 מטרים מכאן".
11. [פסל החזה של מנואל קורדו בויוסה] תעתיק: "בוז'וסה" -> "בויוסה" (Boullosa, שם גליסיאני, ll נהגה "י"). שונה גם ב-h.
12. [פסל 'ליסבון הבנויה מחדש'] דיוק: פומבל "ראש ממשלתו של המלך" -> "השר הבכיר של המלך ז'וזה הראשון" (תפקידו הרשמי היה מזכיר המדינה).
13. [האנדרטה לבורחס] סופרלטיב: "היה מגדולי הסופרים של המאה ה-20" -> "נחשב לאחד הסופרים החשובים". הכללה: "חלק משורה של אנדרטאות לסופרים מאמריקה הלטינית" -> "אחת מכמה יצירות".

### c06 (אבנידה דה ליברדדה ואוונידאש נובאש, חלק ג)
14. [האנדרטה לפינטסילגו] מיקום בטיפ: "בגן קמפו סנטנה" -> "בסביבת קמפו סנטנה" (היצירות של רוי פריירה פזורות סביב הכיכר, לא כולן בגן).
15. [פסל הנערה הנועלת גרב] עברית: "חממה צמחים" -> "חממת צמחים". אחידות תעתיק: "ליאופולדו" -> "לאופולדו" (ב-d, בסיפור, בעובדות וב-`by`), כמו ב-c03, c04, c08, c14.
16. [אנדרטת גבריאלה מיסטרל] תעתיק: "גודוי אלקיאגה" -> "גודוי אלקאיאגה" (Alcayaga; בקלט מופיעה שגיאת הקלדה "Alcavaga").
17. [פסל הנאיאדה] סיוג: "חלק מעיטוריה הועברו... והנאיאדה הגיעה לפארק" -> "וככל הנראה כך הגיעה הנאיאדה לפארק". הדרך שבה הגיעה לפארק אינה בקלט.
18. [פסל האישה העירומה באגם האשטופה פריה] סיוג: "פסל ליסבוני" -> "פסל פורטוגלי"; וייחוס 'המשורר והמוזה' לאנז'וש טיישיירה הבן הוסר. ב-OSM כתוב רק "Anjos Teixeira", בלי לציין אב או בן.
19. [העבודה, ינשוף האבן, סאטיריקון I, המלאך גבריאל] מונח פנימי: "הקלט אינו קושר/מסביר/מאשר" -> "תיאור העירייה אינו קושר" / "בנתונים אין הסבר" / "ב-OSM אין אישור לכך".
20. [האפיפיורית] דיוק: "אחד הקלפים הגדולים בטארוט" -> "אחד מקלפי הארקנה הגדולה בטארוט".
21. [פסל פומונה] אחידות: "מרטינש קוריה" -> "ז'ואקים מרטינש קוריה" (ב-d וב-`by`), כמו באנדרטת סילבשטרה פינייר פריירה.
22. [פסל החזה של פרופ' פרנסישקו ג'נטיל] סופרלטיב לא מאומת: "המוסד הראשון בפורטוגל שהוקדש לחקר הסרטן" -> "מוסד שהוקדש לחקר הסרטן".
23. [אנדרטת סילבשטרה פינייר פריירה] עברית: "פוליגרף" -> "סופר רב־תחומי".
24. [ווינטו גארואה] אחידות תעתיק ב-`by` ובטקסט: "סואריש ברנקו" -> "דומינגוש סואריש ברנקו", כמו באנדרטת המטוס ב-c07 וב-c11.
25. [אנדרטה לאימהות] מיקום: "ובאזור הזה עומדים כמה פסלים בנושא, וביניהם 'אם ובן' בפארק" -> "ובעיר עומדים". 'אם ובן' רחוק כקילומטר.

### c07 (בלם ואז'ודה, חלק א)
26. [אנדרטת אפונסו דה אלבוקרקה] דיוק ואחידות: הפסל של "קושטה מוטה" -> "אנטוניו אוגושטו דה קושטה מוטה (הדוד)" (בסיפור, בעובדות וב-`by`), כדי להבחין בינו לבין האחיין שיצר את אנדרטת רוזה ארוז'ו ב-c06. מרחק: "כמה עשרות מטרים מזרחה נמצא מוזיאון הכרכרות" -> "ממש ממזרח לגן".
27. [דמות חסרת מוח באבן, איי וייוויי] ממצא (WebSearch, DN 2022): יצירות האבן ברחבת מוזיאון הכרכרות הוצגו בתערוכה הזמנית 'Primeira Pedra' שנפתחה ביוני 2022. נוסף סיוג ב-more: "ייתכן שחלקן כבר אינן במקום". ב-d נוסף "לפי הדיווחים זה דיוקן עצמי". "שהוצב לפי OSM ב-2020" -> "שרשום ב-OSM עם השנה 2020" (לפי הדיווח הפסל נוצר במיוחד לתערוכת 2022). סופרלטיב: "אחד האוספים הגדולים בעולם של כרכרות" -> "אוסף גדול של כרכרות". "בלי תשלום" הוסר מ-d.
28. [קרסטן הלר, Dice] שגיאה עובדתית (WebSearch, DN 2022): היצירה היא קובייה ענקית אחת, שבה פתחים במקום נקודות, ולא כמה קוביות. h: "'קוביות'" -> "'קובייה'"; d, סיפור, עובדות ו-kids שוכתבו בהתאם ("כמה נקודות יצאו בכל קובייה, ומה הסכום" -> "אפשר לספור כמה חורים יש בכל צד"). הוסר "כאילו מישהו זרק אותן" ו"עבר לאמנות בשנות ה-90" (-> "בהמשך"). נוסף שהקובייה הוצגה קודם בוונציה, וגם כאן סיוג 'Primeira Pedra'. ההפניות אליה בכרטיסי איי וייוויי ו-Azul Cadoiço תוקנו.
29. [סוסי הים של אנטוניו דוארטה] פרט לא בקלט: "שני הפסלים עומדים זה מול זה, משני צדי הגן" -> "הפסל השני של הזוג רשום ב-OSM בנפרד, באותו חלק של הגן"; וכך גם ב-kids. סופרלטיב: "רוב המונומנטים של בלם" -> "רבים מהמונומנטים".
30. [ארבע הדמויות הנשיות של 1940] שם מטעה: h/e "(פראסה דו אימפריו)" / "Figuras Femininas da Praca do Imperio" -> "(גן אפונסו דה אלבוקרקה)" / "Female Figures of the Afonso de Albuquerque Garden (1940)". לפי תיאור העירייה בקלט הפסלים בבריכות גן אפונסו דה אלבוקרקה, ו-card_name שגוי. ה-more שוכתב בהתאם.
31. [פסל ז'ואאו גונסאלוש זרקו] דיוק: "עד אמצע המאה ה-15" -> "עד המאה ה-15" (זרקו מת כנראה ב-1467). סופרלטיב: "הגן הבוטני הוותיק בפורטוגל" -> "שנחשב לוותיק". "פסלים של ספנים... ביניהם אלבוקרקה" -> "יצירות לזכר דמויות מתקופת המסעות". אלבוקרקה לא היה ספן.
32. [פסל מהטמה גנדי] פרט לא בקלט: "גוף צנום, בגד פשוט ומקל הליכה" -> "ב-OSM אין תיאור של הפסל, אבל... ככל הנראה בדמותו המוכרת". גם ב-kids המקל מסויג.
33. [עמוד הזיכרון של שאו סלגאדו] ניטרליות: "השר החזק" -> "השר". קביעה לא מאומתת: "ורוב העוברים שם אינם יודעים עליה" -> "וקל לעבור לידה בלי לשים אליה לב".
34. [אנדרטת הטיסה הראשונה, בלם] כפילות בין קבצים: h ו-e זהים לכרטיס n5457851270 ב-c12 (אנדרטה אחרת באלוואלאדה). h -> "אנדרטת הטיסה הראשונה מעל דרום האטלנטי בבלם", e -> "...(Belem)". מרחק: אנדרטת הנשר "כמה עשרות מטרים" -> "כ-120 מטרים צפונה" (גם בכרטיס הנשר).
35. [הנרי מור] סופרלטיב: "אולי הפסל הבריטי המפורסם של המאה ה-20" -> "מהפסלים הבריטים המוכרים".
36. [אאולוס] סופרלטיב ותעתיק: "הפסל הפורטוגלי החשוב של סוף המאה ה-18" -> "מהפסלים החשובים"; "ז'ואקין" -> "ז'ואקים" (בכל c07 ו-c08, גם ב-`by` של גרסיה דה אורטה), כמו ברוב הקבצים.
37. [פסלי 'התערוכה של העולם הפורטוגלי' בגן הטרופי] נושא רגיש, סיוג וניטרליות: "שכותרתם" -> "שנקראים ב-OSM"; "הם נוצרו בשביל המדור הקולוניאלי" -> "ככל הנראה נוצרו"; "עיטרו את המדור" -> "עיטרו ככל הנראה". "כיום הם נבחנים כחלק מהדיון בפורטוגל..." (טענה לא מאומתת) -> "הפסלים מעידים על האופן שבו הוצגו המושבות בתערוכה, ועל מורשת התקופה הקולוניאלית יש בפורטוגל דעות שונות".
38. [אנדרטת אוגושטו ז'יל] סופרלטיב וסיוג: "השיר המוכר ביותר שלו... שילדים לומדים כבר דורות" -> "משיריו המוכרים... שלפי המקובל נלמד בבתי הספר". מיקום לא בקלט: "בצד שפונה לרחוב" הוסר.
39. [פסל אבלר ברוטרו] מיקום שגוי: "צפונית לארמון אז'ודה ולגן הבוטני" -> "בחלק הצפוני של אזור בלם ואז'ודה, כ-750 מ' מהמוזיאון הלאומי לאתנולוגיה". לפי הקואורדינטות הפסל כקילומטר מערבית־צפונית־מערבית לארמון.
40. [Azul Cadoiço / ספסל האבן] סיוג 'Primeira Pedra' ב-Azul. סופרלטיב: הספסל "הוא הוותיק בקבוצה" -> "לפי השנים הרשומות המוקדם בקבוצה".
41. [פסל המלך קרלוש הראשון] אחידות תעתיק: "טייזיירה לופש" -> "טיישיירה לופש" (כמו ב-c01), ו-`by` -> "אנטוניו טיישיירה לופש" (התאריך 1942 בסיפור הוא של אנטוניו).

### c08 (בלם ואז'ודה, חלק ב)

45.
