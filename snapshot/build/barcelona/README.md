# ברצלונה: סדר הבנייה (נתונים 2026.10.09a)

נבנתה לפי ה-Playbook (v1.20.2). 333 אתרים בקובץ העיר (270 אתרים ואטרקציות + 63 יצירות "בסיסי"), 219 יצירות נוספות בקובץ "כל היצירות", 28 אירועים, מדריך עיר ומטבע.

## קבצים
- `plan.py`: תוכנית האתרים (קטגוריה, שם, קואורדינטות ראשוניות, רמה, דירוג). `parts.py`: חלוקה לקובצי batch.
- `batch_*.py`: כרטיסי האתרים לפי רובע. `batch_fun.py`: אטרקציות (סעיף 2א). `extra.py`: אתרים שנוספו אחרי איסוף הנתונים. `guide.py`: מדריך העיר והמטבע. `events.py`: אירועים.
- `fixes.py`: אתרים שהוסרו, וקואורדינטות ורובע שתוקנו באימות מול OpenStreetMap.
- `merge.py`: מיזוג לקובץ העיר. `check_batch.py`, `check_guide.py`, `check_events.py`: בדיקות.
- `WRITING_GUIDE.md`, `REVIEW_GUIDE.md`: הנחיות הכתיבה והביקורת. `review/`: רשימות הביקורת (סעיף 9.10).
- `../art/barcelona/`: היצירות. `input/c01..c13.json` נתוני המקור (OSM + ויקידאטה) אחרי סינון, `c01..c13.py` הכרטיסים, `geo.py` שיוך רובע ומרכז לפי קואורדינטות, `marks.py` כרטיסים קיימים שמסומנים כיצירות וכרטיסים שהוסרו, `ART_GUIDE.md`, `check_art.py`.
- `tools/`: הסקריפטים לאיסוף הנתונים ולעיבודם. הסביבה בענן חסומה ל-OSM, ולכן האיסוף נעשה במחשב של בעל היישום: `triparty-barcelona-data.cmd` (Overpass, ויקימסע, ויקידאטה, Nominatim ל-247 אתרים) ו-`triparty-barcelona-osm.cmd` (Overpass עם יומן שגיאות וניסיונות חוזרים). `mkfix.py` יוצר את `fixes.py`, `artprep.py` ו-`artsplit.py` מסננים ומחלקים את היצירות.

## סדר ההרצה
```
cd build/barcelona && python3 merge.py <dataVer>            # כותב triparty-Barcelona.json (בלי יצירות)
cd ../art && python3 merge_art_city.py Barcelona <dataVer>   # מוסיף "בסיסי", כותב triparty-Barcelona-art.json, מעדכן cities.json
```
אחר כך: עדכון `base`, `allN`, `dataVer`, `tb` של Barcelona ב-`triparty-art-settings.json`, ועדכון `version.txt`.
קובצי ה-HTML לא שונו: ברצלונה נטענת מ-`cities.json`, והגדרות היצירות שלה נטענות מ-`triparty-art-settings.json` שבאתר.

## מה לא אומת
מחירים, שעות וסטטוס פתיחה נכתבו מידע כללי ומסויגים בטקסט, כי לא הייתה גישה למקורות עדכניים בזמן הכתיבה. הקואורדינטות אומתו מול OpenStreetMap. פירוט ב-`review/`.
