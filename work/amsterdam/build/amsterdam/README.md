# אמסטרדם: סדר הבנייה (נתונים 2026.11.15a)

העיר נבנתה לפי ה-Playbook (v1.20.2).

**קובץ העיר: 335 כרטיסים**
- 228 אתרים: 43 ברמה מלאה, 24 אתרים יהודיים (ko), 43 טיולי יום.
- 23 אטרקציות: 24 נכתבו, ו-1 הוסרה אחרי האימות באינטרנט.
- 84 יצירות "בסיסי" מ-OSM.
- 13 אתרים קיימים שמסומנים כיצירות.

**עוד באותה גרסה**
- 274 יצירות נוספות בקובץ "כל היצירות".
- 30 אירועים, מהם 7 חוזרים (שבועיים או חודשיים).
- מדריך עיר ומטבע.

נקודת הבסיס היא כיכר הדאם.

## קבצים
**תוכנית ותוכן**
- `plan.py`: תוכנית האתרים. לכל אתר: קטגוריה, שם, קואורדינטות ראשוניות, רמה, דירוג והערות לכותב. שורות SKIP מסוננות.
- `parts.py`: חלוקת התוכנית לקובצי batch, עד 20 אתרים בכל קובץ. ה-regex של `dt=` מסתיים ב-`'` שאחריו `;` או סוף שורה, בגלל הגרש ב"פלנטאז'".
- `batch_*.py`: כרטיסי האתרים לפי רובע, 16 קבצים.
- `batch_fun.py`: האטרקציות (סעיף 2א), לפי `fun_input.json` ו-`FUN_GUIDE.md`.
- `guide.py`: מדריך העיר והמטבע.
- `events.py`: האירועים.
- `fixes.py`: אתרים שהוסרו (DROP) וקואורדינטות שתוקנו (FIX).
  - 89 קואורדינטות תוקנו לפי נתוני OSM שנאספו (`osm_poi.json`) ונבדקו ידנית מול Nominatim.
  - DROP: Paintball Jungle (לא נמצאה עדות לפעילות).

**מיזוג ובדיקות**
- `merge.py`: מיזוג לקובץ העיר.
- בדיקות: `check_batch.py`, `check_fun.py`, `check_guide.py`, `check_events.py`.
- `tools/t_app.py`: בדיקת היישום בדפדפן (Playwright).
- `tools/mk_all.py`: בניית `Triparty-all-cities.html`.

**הנחיות וביקורת**
- `WRITING_GUIDE.md`, `REVIEW_GUIDE.md`, `FUN_GUIDE.md`: הנחיות הכתיבה והביקורת.
- `review/`: דוחות הסוקרים העצמאיים (סעיף 9.10) ודוחות האימות באינטרנט (`web_*`).

**יצירות (`../art/amsterdam/`)**
- `input/c01..c14.json`: נתוני המקור (OSM וויקידאטה) אחרי סינון.
  - מרכז העיר: כל מה שיש לו מידע.
  - וסט וזאוד: ויקידאטה, או אמן ושנה.
  - פאתי העיר: ויקידאטה עם 2 ויקיפדיות לפחות.
- `c01..c14.py`: כרטיסי היצירות. נכתבו 410, ו-52 הוסרו אחרי הביקורת דרך SKIP ב-`marks.py`. סיבות ההסרה:
  - בשטח בתשלום או סגור (ארטיס, גן מוקו, בית קברות סינט ברברה).
  - תצוגה זמנית (נוגוצ'י בגן הרייקסמוזיאום, רודן של ArtZuid).
  - מחוץ לעיר (אמסטלפן, בדהובדורפ).
  - אינם יצירה (גדר, גשר, ספסל, מתקן משחק, חזית).
  - אין עליהם מידע.
- `geo.py`: שיוך רובע ומרכז לפי קואורדינטות. קו האיי מוגדר ב-`ij()`.
- `marks.py`:
  - MARK: 13 כרטיסים קיימים שמסומנים כיצירות, למשל האנדרטה הלאומית, הדוקוורקר, פסלי אנה פרנק, ההומומונומנט ואנדרטת השמות.
  - SKIP: היצירות שהוסרו.
- `ART_GUIDE.md`, `check_art.py`: הנחיות הכתיבה ובדיקת הכרטיסים.

**איסוף נתונים**
- האיסוף רץ ב-GitHub Actions במאגר `daddycoolix/triparty`:
  - הקוד: `collect/collect.py`.
  - ההגדרה: `jobs/amsterdam.json`.
  - התוצאה נכתבת ל-`data/amsterdam/`.
- גיבוי שוטף של כל הבנייה נשמר במאגר תחת `work/amsterdam/`.
- `tools/`: עותקים של `collect.py`, `amsterdam.json`, `artprep.py`, `artsplit.py`, `nom.py` ו-`poi.py`.
  - מאחר ש-`artprep` ו-`artsplit` מצפים לנתונים ב-`dat/` וב-`osm/`, צריך להעתיק את `data/amsterdam` לשם לפני ההרצה.

## סדר ההרצה
```
cd build/amsterdam && python3 merge.py 2026.11.15a              # כותב triparty-Amsterdam.json (בלי יצירות)
cd ../art && python3 merge_art_city.py Amsterdam 2026.11.15a     # מוסיף "בסיסי", כותב triparty-Amsterdam-art.json, מעדכן cities.json
```
אחרי שתי ההרצות צריך לעדכן ידנית:
- ב-`triparty-art-settings.json`, בערך של Amsterdam: `on=1`, `all=1`, `base=97`, `allN=274`.
- `version.txt`.

קובצי ה-HTML לא שונו:
- אמסטרדם נטענת מ-`cities.json`.
- הגדרות היצירות שלה נטענות מ-`triparty-art-settings.json`.
